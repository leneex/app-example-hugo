# Hugo

Пример статического сайта на [Hugo](https://gohugo.io/), который можно развернуть без настройки.

## Параметры деплоя

| Поле | Значение |
| --- | --- |
| Сборка | Статический сайт — сборка Railpack |
| Одностраничное приложение (SPA) | выключено |
| Путь до директории проекта | `/` |
| Директория сборки | `/public` |
| Команда установки зависимостей | оставьте пустым |
| Команда сборки | оставьте пустым |
| Путь проверки состояния | `/` |

Порт указывать не нужно: статический сайт отдаётся на порту 80. Hugo и команду сборки задаёт
`railpack.json`: Railpack ставит Hugo нужной версии и запускает `hugo --minify`, готовые
страницы попадают в `public`.

Для своего сайта на Hugo без `railpack.json` добавьте на вкладке «Переменные» переменную
`RAILPACK_PACKAGES` со значением `hugo` и укажите команду сборки `hugo --minify`.

## <a name="dev"></a>Локальный запуск проекта

```bash
# запуск в режиме разработки
hugo server

# сборка для продакшн
hugo --minify
```

Нужен [Hugo](https://gohugo.io/installation/) 0.169 или новее.
